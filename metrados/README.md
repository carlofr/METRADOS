# Guías de metrados por especialidad

Los archivos de este directorio recogen **listas de verificación**, no replican la Norma Técnica. Antes de cuantificar una partida, consulte:
- reglamento/REFERENCIAS_NORMATIVAS.md
- reglamento/ESTRUCTURA_OE_HU.md
- reglamento/PROTOCOLO_VERIFICACION.md

Especialidades: obras_preliminares (OE.1), estructuras (OE.2), arquitectura (OE.3), sanitarias (OE.4), electricas_mecanicas (OE.5), comunicaciones (OE.6), gas (OE.7) y habilitaciones_urbanas (HU.1-HU.6).

El motor inicial mide geometrías elementales. Para armado, superficies de encofrado y geometrías compuestas, **descomponga el elemento por croquis y valide la norma** antes de registrar la cantidad.
