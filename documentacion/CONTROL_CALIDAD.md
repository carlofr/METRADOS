# Lista de verificación de control de calidad

| Control | Evidencia mínima |
| --- | --- |
| Identificación de proyecto | Nombre, ubicación, responsable, fecha |
| Norma de medición | RD 073-2010, código completo OE/HU, regla de medición específica |
| Normativa de diseño | Norma RNE aplicable y versión/modificatoria |
| Planos | Código, revisión, especialidad, ejes/niveles, croquis |
| Dimensiones | Unidades en metros, dimensiones y cantidad consistentes |
| Descuentos | Sustento de vanos/intersecciones y no duplicidades |
| Consistencia de partidas | Mismo código presupuestal = misma partida y unidad |
| APU | Recursos, rendimientos, precios y fuente/fecha |
| Presupuesto | Metrado × precio, GG, utilidad, impuesto justificado |
| Salida | CSV/JSON, revisión, aprobación y respaldo |

Automatizado en v0.1: validación de campos, números positivos, operaciones y unidades; consolidación por código; descuentos no negativos; detección de códigos conflictivos o sin APU; errores de porcentajes y pruebas unitarias.

**Pendiente de control humano:** cumplimiento de todas las formas de medición, correspondencia con planos, metrado de acero, revisión de diseño, precios y marco contractual.
