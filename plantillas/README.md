# Plantillas CSV

- planilla_metrados.csv: encabezado de entrada para geometrías básicas.
- apu_recursos.csv: encabezado para análisis de precios unitarios por recurso.

Es obligatorio usar **coma** como separador de columna y **punto** decimal, con codificación UTF-8. En Excel puede requerirse importar el CSV según configuración regional.

Los archivos de plantillas NO incluyen partidas normativas completas, dimensiones de obra ni precios. Para practicar, revise ejemplos/README.md. Los códigos EST-001 o ARQ-001 son códigos presupuestales internos, no códigos de la Norma Técnica.
