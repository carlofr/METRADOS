# Contribuir

1. Abra un issue que explique la partida, especialidad, norma aplicable y fuente oficial.
2. No copie textos normativos extensos ni planos o tarifas de terceros. Cite URL, fecha de consulta y norma modificatoria.
3. Separe el **código normativo OE/HU** del **código presupuestal** usado por la herramienta.
4. No cambie unidades ni reglas de descuento sin justificarlo con la forma de medición oficial correspondiente.
5. Añada prueba automatizada para toda fórmula o validación que modifique.
6. Ejecute: python -m unittest discover -s tests -v
7. Indique si los precios son simulados, cotizados o contractuales; use fecha y fuente.
8. Todo cambio de E.030 u otra norma requiere revisar el texto publicado, modificaciones y reglas transitorias.

La incorporación de una nueva partida no implica que su metrado sea correcto ni suficiente para un expediente técnico.
